Data Overview

Pull & Push Data

Pull Data downloads the latest snapshot from your private cloud and replaces the data on this device. Push Data uploads the current device data to the cloud, replacing whatever is stored there. Use these when you want to manually sync in either direction — for example, after configuring a new device or after working offline.

Pull = Cloud → This device Push = This device → Cloud

Data Section Security PIN

This PIN protects the Data section. It is required every time the Data tab is opened — keeping unknown persons away from import, backup, restore and delete controls. It is separate from your login password and your edit PIN.

Data PIN set ✓ Re-locks every time the Data tab is opened

Import Inventory

Upload an Excel / CSV file to replace the current inventory list. Required columns: Spare Name, Available, Reorder Level, Machine/Unit, Maker.

Save & Backup

Save the current data to this device's local storage, or download a full JSON backup that can be restored later on any device.

Export Reports

Generate printable / shareable reports for inventory, issued materials and received materials.

Share

Share the inventory report with your team using the device share sheet, or export a copy to send manually.

Danger Zone

Permanently delete all inventory data, issued records and receipt records. This action requires your login password and cannot be undone. If cloud sync is on, the deletion will also apply to all other devices.
